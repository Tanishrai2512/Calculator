# 🧮 Java Calculator

A simple Calculator application built using **Java** and **Java Swing**. This project performs basic arithmetic operations through a graphical user interface (GUI).

---

## 📌 Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear (C) Button
- User-friendly GUI using Java Swing
- Handles division by zero

---

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/Java-Calculator.git
```

### 2. Open the Project

Open the project in **VS Code** or any Java IDE.

### 3. Compile the Project

```bash
javac calculator/*.java
```

### 4. Run the GUI

```bash
java calculator.CalculatorGUI
```
